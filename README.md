# Jansen Familie Bom

Een custom Dutch party game voor Melvin, Annette, Natalie, Danny, Svea & Robbin — telefoon in het midden van de tafel, 10–15 minuten, bom-doorgeef-mechaniek met persoonlijke categorieën (F1, shoppen, achtbanen, wandelen, games, films, coding, Jansen-huis).

## Openen op je telefoon

Optie 1 — direct lokaal: open `index.html` in je telefoon-browser (bv. via AirDrop of door het bestand te mailen naar jezelf).

Optie 2 — via een simpele webserver op je laptop:

```
cd jansengame
python3 -m http.server 8000
```

Open daarna op je telefoon `http://<laptop-ip>:8000` (zelfde wifi-netwerk).

Optie 3 — GitHub Pages: zet de branch live en open de Pages-URL.

## Spelregels

1. Leg de telefoon in het midden van de tafel.
2. Je ziet een categorie (bv. _Noem een F1-coureur_).
3. Wie de telefoon heeft: noem snel iets dat past en tik om door te geven.
4. Er tikt een verborgen bom (15–30 s). Wie 'm vasthoudt als 'ie ontploft, krijgt een 💥.
5. Na 5 bommen kroont het spel een verliezer met een straf-opdracht.

Zet je geluid aan 🔊.
